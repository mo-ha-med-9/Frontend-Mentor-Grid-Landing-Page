# Frontend Mentor - Grid Landing Page

This is my solution to the **Grid landing page** challenge on Frontend Mentor. This project was a great practical milestone to test my skills in structuring web pages, utilizing modern CSS layouts, and handling live deployments.

## Overview

### Built with

- Semantic HTML5 markup
- CSS custom properties
- CSS Grid & Flexbox
- Mobile-first workflow

### What I Learned

Working on this project helped me gain a deeper, hands-on understanding of several core web development concepts:
- **CSS Grid:** Mastering grid structures to build complex and responsive layouts cleanly.
- **Folder Structure & Relative Paths:** Organizing project files properly and fixing pathing issues for live production servers.
- **GitHub Pages Deployment:** Managing repository settings, case-sensitivity, and ensuring the live site runs without broken links.
